ATLAS VPS Backup

Personal Encrypted Backup System

About the Application

ATLAS VPS Backup is a personal application designed to securely back up and restore VPS configuration, application data, and personal files using Restic, Rclone, and Google Drive.

Google Drive Integration

The application uses Google Drive authorization to store and retrieve encrypted backup files for its authorized owner.

Data Protection

Backup data is intended to be encrypted locally before being uploaded to Google Drive.

This application is intended for private use and is not offered as a public service.
