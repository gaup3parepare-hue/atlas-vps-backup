Privacy Policy

ATLAS VPS Backup

Effective date: November 26, 2026

1. Purpose

This application is intended for personal VPS backup and recovery.

2. Google User Data

The application requests Google Drive access to create, read, update, and manage authorized backup files.

3. Data Usage

Google user data is used solely to provide backup and recovery functionality. It is not used for advertising or AI model training.

4. Data Storage and Security

Backup files are intended to be encrypted with Restic before upload. OAuth credentials are stored on the owner's backup server and protected by operating system permissions.

5. Data Sharing

The application does not sell personal data or intentionally disclose backup content to unrelated third parties. Google Drive provides the storage service used by the application.

6. Data Retention and Deletion

Backup retention is controlled by the owner. The owner may delete backup files from Google Drive and revoke application authorization.

7. Google API Compliance

The application is intended to comply with the Google API Services User Data Policy, including applicable Limited Use requirements.
